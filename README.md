## <a id="pre-requisitos"></a>🛠 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:

- **Java Development Kit (JDK)**: Recomendada versão 17 LTS ou superior.
  - [Download Eclipse Temurin (OpenJDK)](https://adoptium.net/) ou [Oracle JDK](https://www.oracle.com/java/technologies/downloads/)
  - Para verificar a instalação, execute no terminal:
    ```bash
    java -version
    javac -version
    ```
- **Ambiente de Desenvolvimento (IDE / Editor):**
  - [IntelliJ IDEA Community](https://www.jetbrains.com/idea/) *(recomendado)*
  - [Visual Studio Code](https://code.visualstudio.com/) com a extensão [Extension Pack for Java](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-pack)
  - [Eclipse IDE](https://www.eclipse.org/)
- **Git** (opcional, para clonar e versionar): [Download Git](https://git-scm.com/)
